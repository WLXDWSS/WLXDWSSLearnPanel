候选英文学习窗 —— 使用说明
版本：v5（2026-10）
仓库：https://github.com/WLXDWSS/WLXDWSSLearnPanel
========================================

一、启动
--------
1. 把压缩包解压到任意目录（路径里最好别有特殊符号）。
2. 双击 WLXDWSSLearnPanel.exe。
   面板会出现在屏幕右上角，可以用鼠标拖动换位置（位置会被记住）。
3. 不需要安装 Python 或任何运行库，本包已经打包好。
4. 退出：点面板右上角的 ✕。

二、首次使用（必看）
--------------------
点面板右上角 ⚙ 打开设置，在「输入法（手动选择，程序不自动判断）」的下拉框里
选你当前正在用的输入法：

    微软拼音
    搜狗

程序不会自动判断输入法，选好之后才会去读对应的候选。
以后换了输入法，记得回来改一下（面板等待时会显示「当前：xxx」方便核对）。

三、功能
--------
- 打字时，候选词旁边实时显示英文释义（本地 CC-CEDICT 词库，约 12.5 万条，离线可用）
- WPS Office 里也能用（v5 新增，见第七节）
- 本地查不到可开启在线翻译：设置里选 MyMemory（免 key）或百度（需自己填 APP ID / 密钥）
- 主题 4 套（暗夜 / 浅色 / 纸黄 / 高对比），可跟随系统深浅色
- 单行 / 双行、字号 3 档、英文字号比例 0.8×–1.15×、候选编号开关
- 透明面板（透出桌面）、开机自启开关
- 设置窗口会自动收起：开始打字 / 拖动面板 / 点击面板外部

四、注意事项
------------
1. 搜狗路径在传统 Win32 程序里最稳：WPS Office、微软 Word、微信、普通输入框、老式记事本。
   Chrome、Electron 应用、Win11 新版记事本里，搜狗走 TSF，读不到候选，
   这类程序请把设置里的输入法改成「微软拼音」。

2. 本程序是单实例运行的，不能同时开两份
   （同名互斥体 + 搜狗 UDP 端口 52380 独占）。
   提示「已经在运行」时，先结束原来的进程（任务管理器里结束 WLXDWSSLearnPanel.exe）。

3. 若某个程序里搜狗路径不工作（尤其是以管理员权限运行的程序），
   可尝试右键 exe →「以管理员身份运行」。

4. 配置/缓存位置：%LOCALAPPDATA%\WLXDWSSLearnPanel\
   （settings.json / cache.json / pos.json，卸载时可直接删除该目录恢复默认）

五、系统要求
------------
Windows 10 / 11 64 位。无需安装 Python。

六、界面说明
------------
- 顶栏左侧：你刚才键入的拼音（用于核对自己有没有打错）
- 右上角 ⚙：设置    ✕：退出
- 支持拖动面板换位置，位置会被记住
- 面板等待时显示「当前：搜狗 / 微软拼音」，方便核对选对没有

七、v5 更新内容
---------------
- 新增 WPS Office 支持：WPS 是「框架进程 + 文档控件进程」双进程结构，
  旧版只注入前台窗口所在进程，读不到候选；v5 用 GetGUIThreadInfo 取焦点窗口，
  两个进程都注入，WPS 里正常显示英文。
- 修复：鼠标移到面板上会变成沙漏，现在固定为箭头光标。
- 改进：hookdll 写不进配置目录时会明确提示（提示关闭 WPS/记事本后重启面板），不再静默失败。

八、隐私说明
------------
- 本包不含任何个人配置、翻译 API 密钥或用户数据
- 词典查询完全本地，不联网
- 只有开启「在线翻译」后，查不到的词条才会发给你选择的引擎（MyMemory / 百度）
- 百度密钥以 DPAPI 加密存储，换机器或换 Windows 账号需要重填
